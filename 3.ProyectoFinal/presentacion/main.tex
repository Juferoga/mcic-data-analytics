\section{Introducción}
% ------------------------------------------------------------------------------

\begin{frame}{Contexto}
El cáncer de mama es el cáncer más frecuente a nivel mundial y la principal causa de muerte oncológica en mujeres.

\vspace{1em}
\begin{block}{Datos clave}
\begin{itemize}
  \item Las tasas de supervivencia a cinco años superan el 90\% cuando el diagnóstico se realiza en estadios tempranos.
  \item Los algoritmos de Machine Learning han demostrado capacidad comparable o superior a especialistas para clasificar muestras celulares como benignas o malignas.
  \item La clasificación bayesiana permite cuantificar las probabilidades de diagnóstico correcto e incorrecto.
\end{itemize}
\end{block}
\end{frame}

\begin{frame}{Motivación}
\begin{block}{Problema central}
La efectividad de los modelos depende críticamente del flujo de preprocesamiento:
\begin{itemize}
  \item Selección de atributos
  \item Normalización
  \item Elección de métricas adecuadas al contexto clínico
\end{itemize}
\end{block}

\vspace{1em}
Este trabajo implementa un flujo completo de analítica de datos, comparando nueve clasificadores bajo métricas clínicamente relevantes.
\end{frame}

\section{Objetivos}

\begin{frame}{Objetivos del proyecto}
\begin{block}{Objetivo General}
Implementar un flujo de analítica de datos para la clasificación de tumores mamarios, evaluando nueve clasificadores de Machine Learning sobre el dataset WDBC con el \textbf{Recall de la clase Maligno} como métrica principal.
\end{block}

\vspace{1em}
\begin{block}{Objetivos Específicos}
\begin{enumerate}
  \item Aplicar preprocesamiento riguroso y cuantificar su impacto en el rendimiento.
  \item Comparar nueve clasificadores bajo condiciones experimentales idénticas.
  \item Analizar la estabilidad de los modelos mediante validación cruzada 5-fold.
\end{enumerate}
\end{block}
\end{frame}

\section{Dataset}

\begin{frame}{Wisconsin Breast Cancer Diagnostic Dataset (WDBC)}
\begin{columns}
\begin{column}{0.5\textwidth}
\begin{block}{Características del dataset}
\begin{itemize}
  \item \textbf{569 instancias}: 357 benignas (62.7\%) y 212 malignas (37.3\%)
  \item \textbf{30 características numéricas continuas}
  \item Calculadas a partir de imágenes de aspirados con aguja fina (FNA)
  \item Variable objetivo: diagnóstico (Maligno/Benigno)
  \item Sin valores faltantes
\end{itemize}
\end{block}
\end{column}

\begin{column}{0.5\textwidth}
\vspace{-0.5em}
\begin{figure}
\centering

\end{figure}
\end{column}
\end{columns}

\begin{frame}{Desbalance de clases}
\begin{block}{Implicación crítica}
\begin{itemize}
  \item Un clasificador que siempre prediga ``benigno'' obtendría 62.7\% de exactitud sin detectar ningún tumor maligno.
  \item La exactitud por sí sola es \textbf{insuficiente} en problemas médicos con desbalance.
  \item Se requieren métricas complementarias: precisión, recall, F1-score.
\end{itemize}
\end{block}

\vspace{1em}
\textbf{Motivación}: uso del Recall de la clase Maligno como métrica principal.
\end{frame}

\begin{frame}{Preprocesamiento}
\begin{block}{Detección de valores anómalos}
Regla de tres sigma ($\mu \pm 3\sigma$): se detectaron 74 instancias (13\%).

\textbf{Decisión}: se conservaron todos los valores anómalos — corresponden a mediciones clínicas válidas.
\end{block}

\vspace{1em}
\begin{block}{Normalización z-score}
\begin{equation*}
z = \frac{x - \mu}{\sigma}
\end{equation*}
\begin{itemize}
  \item Escalador ajustado \textbf{únicamente} en entrenamiento (\texttt{fit} solo en train)
  \item Evita \textit{data leakage}
  \item Indispensable para SVM y KNN (algoritmos basados en distancias)
\end{itemize}
\end{block}
\end{frame}

\section{Métrica Principal}
% ------------------------------------------------------------------------------

\begin{frame}{Recall de la clase Maligno}
\begin{block}{Definición}
\begin{equation*}
\text{Recall Maligno} = \frac{TP}{TP + FN}
\end{equation*}
\textbf{Sensibilidad}: fracción de tumores malignos detectados correctamente.
\end{block}

\vspace{1em}
\begin{block}{Justificación clínica}
\begin{itemize}
  \item \textbf{Falso negativo} (FN): tumor maligno como benigno → no tratar a un paciente que lo necesita
  \item \textbf{Falso positivo} (FP): tumor benigno como maligno → exámenes adicionales innecesarios
  \item El riesgo clínico de un FN es \textbf{sustancialmente mayor}
  \item Todas las decisiones de hiperparámetros se optimizaron sobre Recall Maligno
\end{itemize}
\end{block}
\end{frame}

\section{Discusión y Conclusiones}
% ------------------------------------------------------------------------------

\begin{frame}{Conclusiones principales}
\begin{block}{Fases del flujo}
\begin{itemize}
  \item \textbf{EDA}: identificó redundancia entre versiones mean/error/worst.
  \item \textbf{Normalización z-score}: indispensable para SVM y KNN.
  \item \textbf{Selección de atributos}: reducción 50\% (30→15) sin pérdida de rendimiento.
  \item \textbf{Recall Maligno}: métrica correcta para el contexto clínico.
\end{itemize}
\end{block}

\vspace{1em}
\begin{block}{Sobre los modelos}
\begin{itemize}
  \item \textbf{Regresión Logística} fue el mejor modelo: mayor Recall (0.943) y precisión perfecta.
  \item El problema es linealmente separable con las 15 características seleccionadas.
  \item Modelos complejos (ANN, RF) no superaron a modelos lineales.
\end{itemize}
\end{block}
\end{frame}

\begin{frame}{Limitaciones}
\begin{itemize}
  \item Dataset de un único centro médico (Universidad de Wisconsin) — limita generalización.
  \item Tamaño reducido (569 instancias) — insuficiente para deep learning.
  \item No incorpora factores de riesgo clínicos (edad, historial familiar, marcadores genéticos).
  \item Validación interna (train/test) — se requiere validación externa.
  \item ANN no incluida en validación cruzada.
\end{itemize}
\end{frame}

\begin{frame}{Aprendizajes clave}
\begin{block}{}
\begin{enumerate}
  \item La exactitud es \textbf{insuficiente} en problemas con desbalance de clases.
  \item KNN obtuvo 90.9\% de accuracy pero solo 84.91\% de Recall Maligno.
  \item La analítica de datos es un proceso integrado: preprocesamiento es tan determinante como el algoritmo.
  \item La validación cruzada permite distinguir modelos con igual rendimiento puntual pero diferente estabilidad.
\end{enumerate}
\end{block}
\end{frame}
